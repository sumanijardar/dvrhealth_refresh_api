5. TROUBLESHOOTING COMMON ERRORS
================================================================================
1. Error: "connect ECONNREFUSED 127.0.0.1:<PORT>"
   - Cause: The python script for that DVR type is not running.
   - Solution: Start the python script in CMD or terminal.

2. Error: "connect ECONNREFUSED <DVR_IP>:<PORT>"
   - Cause: You entered the DVR IP inside the Postman URL instead of localhost/127.0.0.1.
   - Solution: Use http://127.0.0.1:<PORT>/refresh/... in the URL, and put the DVR IP inside the JSON body.

3. Error: "405 Method Not Allowed"
   - Cause: Selected GET instead of POST in Postman.
   - Solution: Change HTTP Method to POST.

4. Error: "404 Not Found: IP '...' not found in all_dvr_live"
   - Cause: The IP does not exist in the 'all_dvr_live' table or has a different dvrname.
   - Solution: Ensure the IP and correct dvrname exist in the 'all_dvr_live' database table.
